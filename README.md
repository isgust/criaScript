# Desafios Criascript - Resolvidos em Java

## Descrição do Repositório

Este repositório contém as soluções em Java para os desafios de programação propostos no quadro **"Desafiando Devs"** do canal **Criascript** no YouTube (https://www.youtube.com/@Criascript).

O objetivo principal deste projeto é praticar e aprimorar minhas habilidades de resolução de problemas e programação em Java, acompanhando os desafios criativos e educativos apresentados pelo Criascript.

## Quadro "Desafiando Devs"

O quadro "Desafiando Devs" consiste em desafios de programação com temas variados, onde um inscrito é convidado a resolver um problema ao vivo em um determinado período de tempo. Este repositório busca implementar soluções para esses desafios, servindo como um registro do meu aprendizado e das diferentes abordagens possíveis.

## Estrutura do Repositório

Cada desafio resolvido estará em sua própria pasta dentro deste repositório, seguindo uma convenção de nomenclatura clara (por exemplo, `desafio_01`, `desafio_nome_do_video`). Dentro de cada pasta, você encontrará:

* O arquivo com a solução em Java (`NomeDoDesafio.java`).
* Possivelmente um arquivo `README.md` específico para aquele desafio, contendo:
    * Uma breve descrição do problema proposto.
    * A minha abordagem para resolver o desafio.
    * Instruções de como executar a solução (se necessário).

## Como Utilizar

1.  **Navegue pelas pastas:** Explore as pastas para encontrar a solução de um desafio específico.
2.  **Visualize o código:** Abra os arquivos `.java` para ver a implementação da solução em Java.
3.  **Execute o código (opcional):** Se você tiver o JDK instalado, poderá compilar e executar os arquivos `.java` para ver a solução em funcionamento. Navegue até a pasta do desafio no seu terminal e execute:
    ```bash
    javac NomeDoDesafio.java
    java NomeDoDesafio
    ```
